2.0Unit Map

本單元目錄

先想像一下出國自助旅行的前一晚，你大概會做兩件事：把行程表再順一次，確認每一站真的知道要去哪；然後把一位熟門熟路的朋友加進 LINE，路上迷路了可以隨時問。今天的課就是這兩件事。

今天是面授，也是整學期唯一一次「先不寫程式碼」的工作坊。上半場，我們把你的品牌企劃修到下週拿得出來用。下半場，你會組出一個自己的 HTML/CSS 助教 Agent。接下來四週是最陌生的一段路，有它陪著會好走很多。

2.1Why Face-to-Face

為什麼今天要面授

你可能有過這種經驗學一門新語言時，每個字單獨看都認得，湊成一句卻不知道在說什麼。接下來的 HTML 和 CSS 很可能就是這種感覺。這不是你不夠努力，任何人第一次碰到都會這樣。

接下來幾週，企劃要改、語法沒學過、還要摸新工具，三件事擠在一起，是整學期最容易想放棄的階段。所以我把最容易卡住的第 2、4 週排成面授。卡住了當場舉手，不用自己悶一整週。

今天不做的事

2.2Plan Checkup

企劃體檢五問

像做健康檢查醫生不會一看到你就說「全身重做」。他量血壓、抽血、看報告，找出哪一項紅字，再針對那一項處理。企劃也是這樣：先檢查，才知道哪裡要動。

拿出你上週交的 Prompt 和企劃初稿，一題一題對照下面五個問題。只要有一題答不出來，這份企劃就還需要再修一輪。現在發現是好事，等到 W9 期中才發現，要改的量會大得多。

#問問自己怎麼知道過關了？
01我的目標客群夠具體嗎？寫「大家」就還不夠。要能說出：什麼情境下、什麼樣的人會走進這家店。
02三個品牌調性的形容詞，彼此不一樣嗎？每個詞都能各自畫出不同的畫面。像「優質、簡約、獨特」這種誰都能貼的詞，畫出來是同一個白色房間，就還不夠。
03網站的每個區塊，都想得到要放什麼嗎？至少 3 個區塊，而且每一塊你都說得出「裡面實際要放什麼」。說不出來的，就只是空模板。
04我有沒有用了空泛的形容詞？把「道地」「職人精神」「簡約現代」這類詞全部圈出來，換成看得到的描述。例如「道地」可以換成湯頭熬幾小時、用哪裡的食材。
05能不能照十二席拉麵那樣拆開？試著把企劃拆成 5 個 <section>。拆不出來，通常代表內容還不夠具體。
體檢完不用整份重寫：通常只有 1–2 題卡住。針對那幾題補上資訊，再問一次 AI 就好，就像體檢只追蹤紅字那幾項。
2.3Your Agent

建立你的 HTML/CSS 助教 Agent

想像你請了一位導遊好的導遊會先帶你站到路口說「你看，左邊那棟紅色的房子」，然後才告訴你「那叫巴洛克式建築」。他也會先問你是第一次來，還是來過很多次。你的助教 Agent 應該就是這樣的導遊。

從下週開始，你會常常盯著一段程式碼，不知道它在做什麼。每次都從頭解釋一遍自己的程度很累。不如現在花一節課，把「助教」這個角色的提示詞寫好、存起來，之後要問問題時直接貼上用。

規則一

請它先說「這段程式碼在畫面上做了什麼」，再解釋語法名稱。順序不能顛倒。因為你現在最需要的是看懂效果，名詞有了畫面才記得住，先背術語只會更混亂。

規則二

導遊不會猜你來過幾次，AI 也不會。你沒說，它就當你什麼都懂。所以提示詞本體裡要明明白白寫上：「請以完全沒學過程式設計為前提回答。」

最重要的一條護欄：導遊給你的地圖，路名要跟街上的路牌一樣，不然照著走也到不了。程式碼也一樣：請 Agent 給你的程式碼必須「打得開、看得到效果」。優先請它給一個單一、自足的 HTML 檔，CSS 直接寫在 <style> 裡。如果一定要分成 HTML、CSS 兩個檔，就要它講清楚檔名怎麼對應、<link> 怎麼寫。這是課堂實測真的踩過的坑：兩個檔名對不上，CSS 就整個失效。
2.4Version History

為什麼要講究這麼細

像一份家傳食譜第一次照著煮，發現太鹹，下次少放一匙鹽；後來發現火太大會焦，再補一句「轉小火」。食譜上的每一行，背後都有一次失敗。提示詞也是這樣長出來的。

這套助教提示詞其實已經改過三次。每一次修改，都是踩到真實的坑以後才補上的護欄。看一遍它的版本沿革，你會更清楚每條規則在防什麼。

版本改了什麼為什麼改
v1原始版本當初假設使用者已經有 HTML/CSS 基礎。問題是，我們班沒有人有。
v2改成零基礎起點目標從「幫我寫」下修成「幫我看懂、幫我改」，並加上「先講效果，再解釋語法」。
v3內容不變，拿到課堂實測確認這套規則放進真實對話裡，還是行得通。
v4加上「打得開、看得到效果」護欄實測發現 AI 常把 HTML/CSS 拆成兩個檔名對不上的檔案，下載後打開，畫面是空的。

你今天組的是屬於自己的 v1。之後遇到新狀況，回來加一條規則就好，就像在食譜旁邊多寫一行筆記，不必整篇重寫。

2.5Two Roles

Copilot 在這門課的兩種角色

像學開車剛開始上路，教練坐在副駕，你自己握方向盤，他只在你快撞到時出聲。等你熟了，才輪到車子的輔助系統幫你開一段，你負責看路、決定要不要介入。

同一個 AI 工具，這學期分兩個階段用。先弄清楚現在是哪個階段，才不會該自己動手時偷懶，該交給 AI 時又硬要手刻。

第 2–5 週｜學語法階段

解釋器＋除錯器

教練坐副駕的階段。你自己先寫、先拆解，卡住了才問 AI。因為這時候你認得的詞還不夠多，沒辦法判斷 AI 給的答案對不對。整段複製貼上，等於在賭運氣。

第 10–14 週｜做專案階段

產生器

輔助駕駛的階段。這時你已經看得懂結構，可以請 AI 直接產出切版和程式碼。你的工作換成判斷、驗證、微調，方向盤還是在你手上。
