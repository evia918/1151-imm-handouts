5.1Selectors

CSS 選擇器速查

CSS 的核心邏輯是「選中誰、套什麼樣式」。選擇器就是「選中誰」的那部分。

選擇器寫法選中什麼
標籤選擇器p { }頁面上所有 <p> 標籤
class 選擇器.card { }所有 class="card" 的元素，可以重複用在很多標籤上
id 選擇器#header { }id="header" 的那一個元素，一個頁面裡只能用一次
後代選擇器.card p { }所有在 class="card" 裡面的 <p>，優先權比單獨的 p 高
常見判讀題：box-sizing: border-box 會讓 width 已經包含 padding 跟 border——不加這行，元素實際寬度會比你設定的數字更大。
5.2Two Ways

傳統 CSS 與 Tailwind：只教辨識

為什麼要多認識 Tailwind？因為第 10 週要用的 AI 切版工具 Google Stitch，產出的程式碼幾乎都是 Tailwind 風格——看得懂，你才知道那些 class 在幹嘛。

傳統寫法

寫在獨立的 CSS 檔案

.btn {
  padding: 12px 20px;
  background: #C1502E;
  border-radius: 8px;
}

Tailwind 寫法

直接把樣式寫在 class 裡

<button class="px-5 py-3
bg-orange-700 rounded-lg">

兩種寫法做出來的效果可以完全一樣——差別只在「樣式寫在哪裡」。這門課不要求你手寫 Tailwind，只要求看到這種一堆縮寫 class 排在一起時，認得出它在做版面設計。

5.3Tailwind Glossary

Tailwind 工具類別辨識卡

看到這些縮寫不用怕，它們都是「一個 class 對應一個樣式」的固定寫法。

p-4 / m-2

內距／外距的等級

text-xl

文字大小等級

bg-orange-500

背景顏色與深淺

flex

啟用彈性排版

rounded-lg

圓角大小

hidden

隱藏這個元素
