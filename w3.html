3.0Unit Map

本單元目錄

從這週開始，HTML 正式登場。但這門課的教法不是「從零手刻一個網頁」，而是「先學會拆解、看懂，再小幅修改」——今天用 vscode.dev 開瀏覽器就能動手，不用裝任何軟體。

3.1Read, Not Write

這週的教法：拆解，不是手刻

這門課的 HTML/CSS 教學有一個明確的原則：教你「讀」，不要求你「寫」。任何要你從零刻出一整個頁面的題目，都不是這門課的標準。

你會做的事

拆解既有頁面

打開一個真實網站或範例檔，對照畫面找出「哪一段程式碼負責哪一塊畫面」。

你不會被要求的事

從零手刻一整頁

不需要背語法、不需要憑空生出一個網頁——看得懂、能小幅修改，就達標。

今天用什麼工具：瀏覽器版的 vscode.dev，不用安裝，直接打開就能編輯、預覽 HTML。桌面版 VS Code 留到第 11 週再裝。
3.2HTML Skeleton

HTML 基本結構速查

任何一個網頁，打開原始碼第一眼看到的骨架都長這樣。先認得這幾行，之後看任何網站的原始碼都不會慌。

標籤／寫法作用
<!DOCTYPE html>告訴瀏覽器「這是一份 HTML5 文件」，一定放在第一行
<html>…</html>整份文件的最外層容器
<head>…</head>放給瀏覽器和搜尋引擎看的設定，不會直接顯示在畫面上
<meta charset="utf-8">宣告文字編碼，少了這行中文字常會變亂碼
<title>…</title>瀏覽器分頁上顯示的標題文字
<body>…</body>真正會顯示在畫面上的所有內容都寫在這裡面
標籤沒封閉會怎樣：忘記寫 </div> 這類收尾標籤，瀏覽器不會報錯，但後面的內容排版常會整個跑掉——這是拆解練習時最常見的踩雷點。
3.3Tag Reference

常見標籤速查卡

拆解網站時，這幾個標籤出現的頻率最高，先把它們的用途記熟。

<h1>～<h6>

標題，數字越小字級越大越重要

<p>

一個段落

<br>

強制換行，沒有結尾標籤

<ol>／<ul>／<li>

有序／無序清單與清單項目

<table>

表格：<tr> 一列、<td> 一格

<img>

插入圖片，靠 src 指定路徑

<a>

超連結，靠 href 指定去哪裡

<strong>／<em>

加粗強調／斜體強調

3.4Ramen Template

十二席拉麵：標準範本

這學期會反覆看到同一個案例——「十二席拉麵」。從品牌企劃、HTML 拆解範例到之後的測驗題目，全部用同一條故事線，不會突然換成陌生的抽象範例。

標準範本用 5 個 <section> 把一個網頁拆成 5 塊內容區——例如品牌故事、菜單、營業資訊、空間介紹、交通位置。你的網站不一定要照抄這個切法，但可以用同樣的邏輯，把自己的企劃拆成「一個 <section> 負責一個主題」。

看範本的重點：不是背它怎麼寫，而是練習回答「這個 <section> 在畫面上對應到哪一塊」——這正是討論①要交的東西。

檢核點今天正式上線

從這週開始，影片裡會出現內嵌檢核點——這是「觀看分數 20%」的計分依據，不是看播放進度。

規則

可以無限次重答

規則

答對就算通過

規則

不會記錄你答錯過幾次

規則

答錯不倒扣

為什麼這樣設計：檢核點是為了確認你真的看過、聽懂內容，不是用來為難人的關卡——答不出來就回去重看那一小段，不會影響分數。
