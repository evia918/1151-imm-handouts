5.2A · Rule Anatomy

CSS 規則三要素：誰、改什麼、改成怎樣

所有 CSS 都由同一個句型組成。看懂這個句型，任何一段 CSS 你都能拆開來讀。

.status-badge {
  background-color: #E05A33;
  color: #111820;
  border-radius: 4px;
}
選擇器

.status-badge

點名：要裝潢「誰」

屬性

background-color

要改「哪一項」

值

#E05A33

要改「成什麼樣子」

四個符號各管一件事

  • { } 包住這個選擇器的所有設定
  • : 屬性和值的分隔，唸作「設為」
  • ; 一行設定的結束，像句號
  • /* */ 註解，寫給人看的，瀏覽器不理它

把它唸成中文

「所有 class 是 status-badge 的元素：背景設成橘紅色、文字設成深藍黑、四個角變圓 4 像素。」

→ 唸得出來，就代表你讀懂了。這是本週最重要的閱讀技巧。

常見錯誤：漏掉分號 ;，下一行設定會跟著失效——第 4 週「改壞再修好」就練過這種錯誤。
5.3A · Where CSS Lives

CSS 會出現在哪裡？三個位置

同樣一行「文字變深色」，可以寫在三個地方。你不用決定要用哪一種，只要看到時認得出「這是樣式」。

① 外部 .css 檔
<link rel="stylesheet"
      href="style.css">

正式網站最常見，一份 CSS 給很多頁共用。第 11 週用 VS Code 開專案時會看到。

② 內部 <style>
<head>
  <style>
    .btn { color: #111820; }
  </style>
</head>

十二席拉麵頁就是這種。全部寫在同一個 HTML 檔裡，適合單頁與教學。

③ 行內 style=""
<p style="color: red;">
  今晚公休
</p>

直接寫在標籤上，只影響這一個元素。AI 偶爾會產生這種寫法，看得懂即可。

辨識重點：三種寫法效果一樣，差別只在「寫在哪」。還有第四種——Tailwind 把樣式寫在 class 裡，留到 5.14 介紹。
5.4A · Selectors

三種選擇器：點名的三種方式

選擇器就像老師點名：可以點「全班」、點「某一組」，也可以點「某一個學號」。

標籤選擇器
/* 頁面上所有 <p> */
p { line-height: 1.6; }

沒有符號，直接寫標籤名。點「全班」。

class 選擇器　.
/* 所有 class="btn" */
.btn { border-radius: 4px; }

句點開頭。點「某一組」，可重複用在很多標籤上，最常用。

id 選擇器　#
/* 唯一的 id="map" */
#map { padding: 32px 0; }

井字號開頭。點「學號」，一個頁面只能有一個。

最容易錯：CSS 寫 .btn，HTML 裡是 class="btn"——HTML 裡不寫句點。#map 對應 id="map" 也一樣。
5.5A · Who Wins

樣式打架時，誰說了算？

同一個元素被好幾條規則點到，而且設定互相衝突時，瀏覽器只聽其中一條。判斷只需要兩個原則。

<h1 id="logo" class="brand-title">十二席拉麵</h1>

h1           { color: white;   }
.brand-title { color: #E8DDC7; }
#logo        { color: #E05A33; }
原則 1　越精準越優先

id ＞ class ＞ 標籤。點學號比點小組精準，點小組比點全班精準。

後代選擇器 .card p（「卡片裡的 p」）比單獨的 p 精準，所以也比較優先。

原則 2　一樣精準看順序

兩條規則一樣精準時，寫在後面的那條贏。

不需要會算權重分數，只要會判斷「哪一條比較精準」。

◆ 檢核點 1：上例 h1 的文字最後是什麼顏色？

橘紅色 #E05A33。三條規則都點到同一個 h1，#logo 是 id 選擇器，最精準，所以它贏。

實務提醒：AI 幫你改的 CSS「沒反應」，十之八九是被別條規則蓋掉了。5.7 會教你用 F12 找出被蓋掉的那一行。
5.6B · Read the Code

示範：拆解 CSS 四步驟

以後遇到任何網頁、任何 AI 產生的 CSS，都用這四步驟讀。這裡以拉麵頁的橘紅色標籤為例。

STEP 1

在畫面上找到區塊

例：橘紅色的「今晚有開」標籤

STEP 2

在 HTML 找它的 class

<div class="status-badge">

STEP 3

到 <style> 找同名規則

.status-badge { … }

STEP 4

逐行說出畫面效果

把每一行唸成中文

今晚有開，營業至 04:00
.status-badge {
  background-color: #E05A33; /* 橘紅底 */
  color: #111820;            /* 深色字 */
  font-weight: 700;          /* 粗體 */
  padding: 6px 12px;         /* 字和邊緣之間留空 */
  border-radius: 4px;        /* 四角微圓 */
  font-size: 0.9rem;         /* 字小一點 */
  margin-bottom: 12px;       /* 和下一行隔開 */
}
STEP 4 是本週核心能力：右邊的灰色註解，就是你要能自己講出來的內容。用「畫面語言」說，例如說「字和邊框之間留空」，而不是只說「padding」。

單位小知識：px 是像素；rem 是相對字級，1rem 約等於 16px。知道它們代表「大小」就夠了。

5.9B · Box Model

盒模型：每個元素都是一張卡牌

瀏覽器把每個元素都看成一個長方形盒子。想像桌上並排的三張卡牌，就能分出盒子的四層。點下面的按鈕，逐一看每一層在哪裡。

content 內容

真正的文字或圖片。width／height 預設只量這一層。

padding 內距

框和內容之間的留白。背景色會塗到這裡（卡牌的色面）。

border 邊框

包住內容與內距的外框線，可設粗細、樣式、顏色。

margin 外距

盒子和旁邊盒子的距離。透明，背景色不會塗到這裡。

回到拉麵頁：.status-badge 的 padding: 6px 12px 是標籤裡上下 6、左右 12 的留白（橘紅色會塗到）；margin-bottom: 12px 是它和下一行之間的透明距離。
5.10B · box-sizing

box-sizing: border-box —— 寬度不再「變胖」

測驗①一定會出的計算題，只需要加法。條件都一樣：width: 200px、padding: 20px、border: 5px。

預設 content-box
容器只給 200px
內容 200

實際佔 250px：5 ＋ 20 ＋ 200 ＋ 20 ＋ 5。width 只量內容，padding 和 border 再往外加，比容器多出 50px，版面就被撐破。

加上 box-sizing: border-box
容器只給 200px
內容 150

總寬鎖在 200px：width 改成量「整個盒子」，瀏覽器自動把內容縮成 150px。

.btn {
  width: 100%;
  padding: 14px 0;
  box-sizing: border-box;
}

拉麵頁為什麼要寫它？

「開啟地圖」按鈕寬 100% 又有內距。沒有 border-box，按鈕會是 100% 再加上內距，超出手機畫面；有了它，剛好等於畫面寬。.container 也寫了同一行。

◆ 檢核點 2：width:200px、padding:20px、border:5px，加了 border-box 後總寬是多少？

200px。border-box 讓 width 包含 padding 和 border，內容會自動縮成 200 − 40 − 10 ＝ 150px。沒加的話是 250px。

5.12B · Flexbox

Flexbox：看到 display:flex 就是「排隊」

看到 display: flex，就把它想成「裡面的子元素開始排隊」。按按鈕切換排隊方向。

.btn-group {
  display: flex;          /* 開始排隊 */
  flex-direction: column; /* 排隊方向 */
  gap: 12px;              /* 每個人的間距 */
}
查看菜單查看座位開啟地圖
看到這個意思
display: flex裡面的子元素開始排隊
flex-directionrow 橫排／column 直排
justify-content沿著排隊方向怎麼分配位置（置中、靠左、平均分散…）
align-items另一個方向怎麼對齊
gap隊伍裡每個人之間的距離

另一個排版工具 Grid（display: grid）是「切格子排版」，看到 grid-template-columns 知道它在決定「分幾欄」即可。手機／桌面版的切換留到第 13 週。

5.14C · Why Tailwind

為什麼要認識 Tailwind？

你不一定要寫它，但你拿到的 AI 產出，很多都是它。

1　第 10 週就會遇到

Google Stitch 產出的網頁就是 HTML＋Tailwind，class 裡一長串都是樣式。

2　AI 常用的輸出格式

許多 AI 切版工具與範例都用 Tailwind，這是你最常「讀到」的樣式寫法。

3　規律很好認

它只是把 CSS 的「屬性：值」縮寫後直接寫進 class，看懂規律就能讀。
