12.2Scenario

凌晨三點，網站還說「營業中」

十二席拉麵凌晨兩點打烊。一位客人三點看到網站寫「營業中」，騎車過去，鐵門是拉下來的。

HTML 沒錯

標籤都在、結構正確。

CSS 沒錯

顏色漂亮、排版正常。

錯的是「判斷時間」的那幾行 JavaScript。這週學的，就是怎麼找到這幾行、看懂它、讓 Gemini 幫你修，而且確認修對了。
12.3Metaphor

三兄弟：骨架、裝潢、水電

HTML · 骨架

哪裡是門、哪裡是牆、哪裡是窗。
「這裡有一個按鈕」。

CSS · 裝潢

牆刷什麼顏色、門多寬。
「按鈕是橘色、圓角」。

JS · 水電開關

按下開關，燈會亮。
「按了按鈕，選單會打開」。

所以判斷原則是：畫面「長得不對」→ 先看 CSS；畫面「按了沒反應、內容不對」→ 先看 JS。

12.5Read Method

讀 JS 只要問三個問題

就像看電燈開關的配線：這條線接到哪盞燈？按下哪個開關才會動？動了之後發生什麼事？

問題程式碼長相白話
① 抓誰document.getElementById('menu')找到 id 是 menu 的那個元素
② 等什麼addEventListener('click', …)等它被點擊
③ 做什麼classList.toggle('hidden')
textContent = '休息中'		切換顯示／隱藏
把文字換掉
12.6A · Demo 1

示範①　讀懂手機選單按鈕

<button id="menuBtn">☰</button>
<nav id="menu" class="hidden">…</nav>

<script>
  // ① 抓誰：按鈕和選單
  const btn  = document.getElementById('menuBtn');
  const menu = document.getElementById('menu');
  // ② 等什麼：按鈕被點擊
  btn.addEventListener('click', function () {
    // ③ 做什麼：選單的 hidden 有就拿掉、沒有就加上
    menu.classList.toggle('hidden');
  });
</script>

hidden 是 Tailwind 的 class，等於 CSS 的 display:none（W5 解碼表）。

所以這段程式的白話是：按一下 ☰，選單出現；再按一下，選單消失。

注意 JS 和 HTML 靠 id 對上。id 拼錯一個字母，開關就接不到燈。

12.7B · Follow Along 1

跟做①　讀懂「營業中」標籤

請暫停影片，用三個問題讀這段程式，再展開答案對照。

const badge = document.getElementById('status');
const hour  = new Date().getHours();   // 現在幾點（0–23）

if (hour >= 21 || hour < 2) {
  badge.textContent = '營業中';
} else {
  badge.textContent = '休息中';
}
展開參考答案
  • 抓誰：id 是 status 的標籤
  • 等什麼：不用等，網頁一打開就執行一次
  • 做什麼：21 點以後或凌晨 2 點前顯示「營業中」，其他時間「休息中」
  • || 讀作「或」：兩個條件只要成立一個就算數

Console：瀏覽器幫你寫好的報案單

JS 壞掉時，畫面通常什麼都不說，只是「沒反應」。但瀏覽器在後台已經寫好一張報案單了。

01

按 F12

02

切到 Console

上方分頁「主控台」

03

找紅字

紅字＝錯誤，黃字＝警告

04

看最右邊

index.html:42＝第 42 行

Uncaught TypeError: Cannot set properties of null (setting 'textContent')
    at index.html:42

12.9Common Errors

三種最常見的壞法

Console 說白話第一步檢查
Cannot set properties of null開關接不到燈：抓的東西不存在id 拼字、大小寫；<script> 是不是放在元素前面（在 head 裡）
… is not defined叫了一個不存在的名字變數或函式名稱拼錯
（沒有紅字，但結果不對）配線沒斷，邏輯錯了條件判斷：時間範圍、"false" 字串不等於 false
第三種最難找：沒有報案單，只能自己讀程式。12.2 的凌晨三點事件就是這一種。

12.11B · Follow Along 2

跟做②　找出壞掉的那一個字

下面這段程式，Console 顯示 Cannot set properties of null。先自己找，找不到再問 Gemini。

<span id="status"></span>

<script>
  const badge = document.getElementById('Status');
  badge.textContent = '營業中';
</script>
展開參考答案

'Status' 的 S 是大寫，HTML 裡是小寫 status。JS 分大小寫，所以抓到 null（空的），第二行就壞了。這跟 W11 檔名要全小寫是同一個道理。

12.12Verify

AI 的建議，你負責驗證

Gemini 很會修，但它看不到你的畫面，有時候會「修好一個、弄壞兩個」。

✗ 這種建議先別照用

「建議你把整份檔案改成以下版本……」（貼回 300 行）
它可能順手把你的配色、文字也換掉了。

○ 這種比較安全

「第 42 行的 'Status' 改成 'status'。」
改一處、看得懂為什麼、改完可以馬上驗證。

驗證就是 W11 的三步：先備份 → 只改一處 → 存檔看畫面，Console 紅字消失、結果正確才算數。
