11.5Folder

專案資料夾長這樣

my-site/              ← 整個網站就是這個資料夾
├── index.html        ← 首頁，名字固定是這個
├── menu.html         ← 第二頁（期末那「一頁」）
└── images/
    ├── logo.png
    └── ramen-01.jpg

命名四規則

  1. 首頁一定叫 index.html
  2. 全部小寫英文
  3. 不要空格，用 - 連接
  4. 不要中文檔名

為什麼？網站上線後住在別人的伺服器上，那裡把 Logo.png 和 logo.png 當成兩個不同的檔案。在自己電腦看得到，上線卻破圖，九成是這個原因（W15 會再遇到它）。

11.8Concept

中文為什麼怪：字型的「點餐順序」

打開 Stitch 頁面，英文很好看，中文卻粗細不一、像拼湊出來的。原因藏在 font-family 這個屬性裡。

font-family 像點餐：「我要 A，沒有的話 B，再沒有就隨便」。

Stitch 只點了英文字型（例如 Inter）。英文字型裡沒有中文字，瀏覽器只好每個中文字都「隨便」，於是你看到的是系統臨時湊出來的字。

font-family: "Inter", sans-serif;
/* Inter：有英文、沒有中文
   sans-serif：瀏覽器自己找一個「隨便」 */
如果看到的是「□□□」或「銝剜」這種真正的亂碼呢？

那是編碼問題，不是字型問題。檢查 <head> 裡有沒有 <meta charset="UTF-8">，存檔時編碼也要是 UTF-8（VS Code 右下角會顯示）。

11.9A · Demo 2

示範②　一行載入、一行套用

在 index.html 的 </head> 正上方，貼上這兩行：

<!-- ① 向 Google Fonts 借思源黑體（Noto Sans TC） -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@400;700&display=swap">
<!-- ② 點餐順序第一位改成思源黑體 -->
<style>body{font-family:"Noto Sans TC",sans-serif;}</style>
為什麼放在 </head> 正上方：CSS 是後寫的蓋掉先寫的（W5「樣式打架」）。放在最後面，你的設定最有機會贏。

有些標題還是舊字型？那些元素身上有 Tailwind 的字型 class（例如 font-display），優先權比 body 高。把那一行貼給 Gemini，問「這個 class 在畫面上做什麼」。
圖示變成英文字（如 arrow_forward）？你可能用了 *{font-family:... !important}，把圖示字型也蓋掉了。改回 11.9 的寫法，只設定 body。
11.11AI Role

Gemini 換角色：從解釋器到產生器

W2–W5，Gemini 是幫你看懂程式的翻譯。從這週到 W14，它可以幫你寫程式了，但你要先看得懂它寫了什麼。

# 請 Gemini 改程式的提問模板
我的狀況：用 Google Stitch 匯出的 index.html，在 VS Code 開啟。
我想要：讓「營業時間」區塊的字再大一點。
相關程式碼：（貼上那一段，不要貼整份檔案）
請你：先說明這段程式碼在畫面上做什麼，
      再告訴我要改哪裡、改成什麼。
驗證三步：改之前先存一份備份 → 一次只改 AI 建議的一處 → 存檔看畫面，跟你要的一樣才算數。
