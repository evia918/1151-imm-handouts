11.3Why Now

為什麼現在才裝桌面版

W3–W5 用的 vscode.dev 是「借來的工作台」，打開網頁就能用，但它不擅長管理整個資料夾。現在你有了自己的專案，該換一張自己的桌子了。

vscode.dev（W3–W5）桌面版 VS Code（W11 起）
安裝不用要，約 5 分鐘
介面幾乎一模一樣，所以不是學新工具
管理整個資料夾可以，但每次要重新授權開一次，之後都記得
即時預覽有限可裝擴充套件 Live Server

11.5Folder

專案資料夾長這樣

my-site/              ← 整個網站就是這個資料夾
├── index.html        ← 首頁，名字固定是這個
├── menu.html         ← 第二頁（期末那「一頁」）
└── images/
    ├── logo.png
    └── ramen-01.jpg

命名四規則

  1. 首頁一定叫 index.html
  2. 全部小寫英文
  3. 不要空格，用 - 連接
  4. 不要中文檔名

為什麼？網站上線後住在別人的伺服器上，那裡把 Logo.png 和 logo.png 當成兩個不同的檔案。在自己電腦看得到，上線卻破圖，九成是這個原因（W15 會再遇到它）。

11.6B · Follow Along 1

跟做①　建立你的專案資料夾

請暫停影片，跟著做。

  • 先開啟副檔名顯示：檔案總管 → 檢視 → 顯示 → 勾「副檔名」
  • 在「文件」裡新增資料夾 my-site
  • 把 W10 匯出的 Stitch 檔案放進去，改名為 index.html（.zip 請先解壓縮）
  • 新增 images 資料夾（有圖片就放進去）
  • VS Code → 檔案 → 開啟資料夾 → 選 my-site
  • 對 index.html 按右鍵 → Open with Live Server（或直接雙擊用瀏覽器開）
  • 按 Shift+Alt+F 自動排版，擠成一團的程式碼會變整齊
  • 截圖左側的檔案總管（評量③要交）
常見錯誤①：用「開啟檔案」而不是「開啟資料夾」。左側看不到資料夾結構，就是開錯了。
常見錯誤②：沒開副檔名就改名，檔案變成 index.html.html，上線後 404。開了副檔名一眼就看得出來。
從現在起的分工規則：版面、配色等大方向，匯出前在 Stitch 改；匯出後只在 VS Code 改。回 Stitch 改完再匯出一次，你在 VS Code 手改的地方會被整份蓋掉。

11.8Concept

字型的「點餐順序」：font-family

W10 你在 Stitch 的 Theme 面板選了 Noto Sans TC，中文正常顯示。但清單裡只有幾十種字型，像芫荽（Iansui）這種手寫風中文字型就不在裡面。想用，就得自己改程式碼。

font-family 像點餐：「我要 A，沒有的話 B，再沒有就隨便」。

瀏覽器從左到右找，第一個「有載入、又有這個字」的字型就拿來用。所以換字型要做兩件事：

  1. 載入：讓瀏覽器拿得到芫荽（加一行 <link>）
  2. 指定：把芫荽排在點餐順序第一位
font-family: "Iansui", "Noto Sans TC", sans-serif;
/* Iansui：第一志願，芫荽
   Noto Sans TC：芫荽沒有的字，用思源黑體補
   sans-serif：前兩個都沒有，瀏覽器自己找 */
只做一半最常見：只載入不指定，畫面不會變；只指定不載入，瀏覽器找不到芫荽，直接跳到第二位。兩處都要改。
如果看到的是「□□□」或「銝剜」這種真正的亂碼呢？

那是編碼問題，不是字型問題。檢查 <head> 裡有沒有 <meta charset="UTF-8">，存檔時編碼也要是 UTF-8（VS Code 右下角會顯示）。

11.9A · Demo 2

示範②　兩處程式碼，換成芫荽字體

芫荽是台灣字型設計師 But Ko 的開源字型，收錄在 Google Fonts，免費、可商用。

① 載入

在 <head> 裡加一行

找到 Stitch 原本載入 Google Fonts 的 <link>，在它下面貼上：

<!-- 向 Google Fonts 借芫荽字體 -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Iansui&display=swap">
② 指定

用「取代」把字型名稱換掉

按 Ctrl+H，上面填你在 Stitch 選的字型名稱，下面填芫荽，按「全部取代」：

尋找：Noto Sans TC
取代：Iansui

只換名字，不動名字外面的引號（單引號、雙引號都一樣）。左下角會顯示取代了幾處。

為什麼用「取代」而不是自己加一行 CSS：Stitch 的程式碼可能在好幾個地方寫了字型名稱（例如 Tailwind 設定裡的 fontFamily）。只改一處，其他地方還是舊字型。用取代可以一次全部換到。
網址裡的不會被換到：Stitch 原本那行 <link> 網址寫的是 Noto+Sans+TC（用 + 連接），不會被取代，留著不影響。想加 11.8 的備胎寫法，可以之後請 Gemini 幫你調整。
11.10B · Follow Along 2

跟做②　換上芫荽，截前後對比

  • 修改前先截圖（W10 跟做②已截過可沿用）
  • 照 11.9 做 ①載入 ②取代 → 存檔（Ctrl+S）→ 重新整理瀏覽器
  • 修改後截圖，兩張放在一起比對
畫面完全沒變？依序檢查：① <link> 網址有沒有打錯 ② 按 Ctrl+F 搜尋 Iansui，看取代有沒有成功 ③ 有沒有存檔。
顯示「取代了 0 處」？你在 Stitch 選的不是 Noto Sans TC。按 Ctrl+F 搜尋 font，找到檔案裡實際寫的字型名稱，再用它來取代。

設計判斷：芫荽適合放哪裡？

芫荽只有一種粗細。標題的粗體會被瀏覽器「硬加粗」，筆畫可能變糊。手寫感適合溫暖、親切的品牌，但不一定適合每一段文字。全頁都換、只換標題，還是只換店主的話？選一種並想好理由，W16 同儕互評時會被問到。

不一定要用芫荽：到 fonts.google.com，語言選「Chinese (Traditional)」，挑一個 Stitch 清單裡沒有、又符合你品牌調性的字型，做法完全一樣。
11.11AI Role

Gemini 換角色：從解釋器到產生器

W2–W5，Gemini 是幫你看懂程式的翻譯。從這週到 W14，它可以幫你寫程式了，但你要先看得懂它寫了什麼。

# 請 Gemini 改程式的提問模板
我的狀況：用 Google Stitch 匯出的 index.html，在 VS Code 開啟。
我想要：讓「營業時間」區塊的字再大一點。
相關程式碼：（貼上那一段，不要貼整份檔案）
請你：先說明這段程式碼在畫面上做什麼，
      再告訴我要改哪裡、改成什麼。
驗證三步：改之前先存一份備份 → 一次只改 AI 建議的一處 → 存檔看畫面，跟你要的一樣才算數。
